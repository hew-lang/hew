# Hew 0.11.1

Hew can export functions and records to C and infer return types across generic calls. This release also improves Unicode indexing and adds shared proxy settings for native tools.

## Language and C interoperability

- You can place a comma after a block-bodied arm in `match` or `select`, including a `select` timeout arm. The formatter omits this optional comma.

- C callers can now pass and return Hew records by value. Mark each compatible record with `#[repr(C)]` and mark a concrete function with `#[export]` or `#[export("symbol")]`. A raw export runs deferred cleanup on a fault and terminates the process. Use the checked host SDK when the caller needs to recover.

- Functions and methods declared with `-> _` can infer their result across forward generic calls and recursive groups when a concrete return value establishes the type. Supply an explicit result type when the recursive calls alone leave it ambiguous.

- Machine events named `left` or `right` can coexist with local variables of the same name in an imported module. This fixes the collision encountered in Hewbot.

## Libraries and networking

- The calendar supports years −999999 through +999999. Custom patterns use the Rust `time` crate’s strftime dialect. Use `%z` for an offset such as `+0000`. If your ISO timestamp pattern used `%f`, `%.f`, `%.9f` or `%:z`, use `datetime.to_iso8601` and `datetime.parse_iso8601` to preserve nanoseconds and read offsets.

- YAML decoding now uses a pure Rust parser on native and browser targets. The Hew API stays the same. In flow collections, separate the explicit key marker from its collection with a space, as in `{? [north, west]: corner}`. Rust callers can name decoded values as `hew_codec::yaml_value::Value`.

- Set `HTTP_PROXY` and `HTTPS_PROXY` for package downloads, native HTTP requests, Observe and the optional OTLP exporter. Use `NO_PROXY` for hosts you reach directly. Plain HTTP uses proxy forwarding and HTTPS uses a CONNECT tunnel. On Linux, install a private CA in the system trust store or point `SSL_CERT_FILE` to a trusted CA bundle. Rust programs that used the old Hew connector for package registry operations can use `hew_pkg::client::RegistryClient`.

- The optional component host uses a patched Wasmtime release. Compiled Hew reactor components now receive the stack space required for fault recovery.

- The SMTP library has been updated to address six published advisories.

## Performance and profiling

- Programs that construct large owning tuples compile faster. On the measured Linux machine, checking a 2,048-field tuple fell from 8.62 seconds to 2.64 seconds.

- Unicode indexing uses existing UTF-8 checkpoints more efficiently. The word-frequency example used 11.8% fewer instructions on the measured mixed-text corpus.

- To profile an optimized program with Hew source locations, build it with `hew build -g --opt-level 2 microgpt.hew`, then run `samply record ./microgpt`. The build command now documents this combination.
