# Hew 0.8.0

Hew 0.8 reduces callable boilerplate, makes optional arguments ordinary language
behaviour and connects resource safety to supplied services. It continues
language edition 2026.

## Inference and private state

A closure can infer a generic signature when its body supports one:

```hew
fn main() {
    let identity = |value| value;
    assert(identity(42) == 42);
    assert(identity("hello") == "hello");

    let count = 0;
    var counted = |value| {
        count += 1;
        (count, value)
    };
    let (first, _) = counted("one");
    let (second, _) = counted(2);
    assert(first == 1 && second == 2 && count == 0);
}
```

Mutation belongs to the closure's private environment. Callable capabilities
still control sharing, cloning and invocation. An independent clone copies the
current environment; it does not share mutable state implicitly. Expected
callable types supply parameter and result types where context makes them clear.

## Defaults and machine stepping

```hew
fn label(value: string, prefix: string = "hew") -> string {
    f"{prefix}: {value}"
}

fn main() {
    println(label("ready"));
    println(label("ready", prefix: "worker"));
}
```

Defaults are ordinary expressions checked in the declaration's scope. Written
arguments run first in source order; omitted defaults run in parameter order.
Supplying an argument skips its default completely. Defaults can allocate,
suspend or fail under ordinary ownership and effect rules. Functions, inherent
methods, trait methods, actor receives, actor initializers and supervisor inputs
use this same contract. The trait declaration owns inherited defaults.

Machines use `machine.step(event)` or `machine.step(event, limit: 64)`. Both
return `Result<Step, MachineStepError>` and use one evaluator. The default limit
is 1,024 transition sets; invalid limits and exhaustion preserve the original
state and outputs. The observed-machine owner keeps its existing report-returning
`step` contract.

## Exact time and owned capacity

`0.25s` is exactly `250ms`; the compiler converts decimal literals with integer
arithmetic. Values finer than the supported nanosecond precision are diagnosed.
Timeout APIs take `duration`, so call sites show units instead of relying on an
implicit integer scale.

`sem.lease()` acquires an owned capacity unit. Closing it, leaving its scope,
faulting or cancelling returns the unit once. Explicit semaphore clones share
the permit count. Raw acquisition and release remain useful for signalling.
The compiler warns about locally certain progress failures, including exhausting
known capacity while retaining the leases needed to restore it. Native and
sandbox execution share the ownership and waiting behaviour.

## Supplied services and macro tools

Confined code may use the services it receives, including acquired file,
network and process handles. Ambient acquisition and opaque authority escapes
are rejected transitively, including calls introduced by omitted defaults.
This boundary follows checked operations rather than a directory naming rule.

`hew tool expand main.hew` renders the whole expanded file;
`hew tool expand main.hew --at 12:5 --json` selects an expansion and includes its
source provenance. Editor commands provide the same views for unsaved code.
Rendered expansion text is for inspection: the compiler retains hygiene facts
that plain source text cannot represent. Generated tests use ordinary `hew test`
discovery. See the [macro guide](../guides/macros.md).

The release also updates `ctutils` to 0.4.4 for the constant-time mask and
comparison fixes in [RUSTSEC-2026-0385](https://rustsec.org/advisories/RUSTSEC-2026-0385),
and Tokio to 1.53.3 for the I/O-safety correction in
[RUSTSEC-2026-0386](https://rustsec.org/advisories/RUSTSEC-2026-0386).

The [migration guide](../migrations/v0.8.0.md) lists changed spellings and APIs.
