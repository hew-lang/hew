# Hew 0.11.1

Hew can export functions and records to C and infer return types across generic calls. This release also improves Unicode indexing and adds shared proxy settings for native tools.

## Language and C interoperability

- Inherent methods and associated functions follow the same visibility rules as free functions. Use `fn` within the defining module, `package fn` across modules in one package, and `pub fn` for callers in other packages. Trait methods use the visibility of their trait. You can also pass an accessible constructor or other associated function directly as a callback, including one imported from another module.

- Regex match arms can use a named group in the guard and body. For example, `re"^hello (?P<name>.+)$" if name != "skip" => name` returns the captured name. A group that always participates has type `string`. A group the pattern can skip has type `Option<string>`, so you can distinguish an absent group from an empty match.

- You can place a comma after a block-bodied arm in `match` or `select`, including a `select` timeout arm. The formatter omits this optional comma.

- C callers can now pass and return Hew records by value. Mark each compatible record with `#[repr(C)]` and mark a concrete function with `#[export]` or `#[export("symbol")]`. A raw export runs deferred cleanup on a fault and terminates the process. Use the checked host SDK when the caller needs to recover.

- Functions and methods declared with `-> _` can infer their result across forward generic calls and recursive groups when a concrete return value establishes the type. Supply an explicit result type when the recursive calls alone leave it ambiguous.

- Machine events named `left` or `right` can coexist with local variables of the same name in an imported module. This fixes the collision encountered in Hewbot.

## Libraries and networking

- JSON, YAML and TOML access errors report both the expected and actual value types. For example, the order reader reports `item 1: units: json: expected Integer, found String` when the quantity is quoted.

- The calendar supports years −999999 through +999999. Custom patterns use the Rust `time` crate’s strftime dialect. Use `%z` for an offset such as `+0000`. If your ISO timestamp pattern used `%f`, `%.f`, `%.9f` or `%:z`, use `datetime.to_iso8601` and `datetime.parse_iso8601` to preserve nanoseconds and read offsets.

- YAML decoding now uses a pure Rust parser on native and browser targets. The Hew API stays the same. In flow collections, separate the explicit key marker from its collection with a space, as in `{? [north, west]: corner}`. Rust callers can name decoded values as `hew_codec::yaml_value::Value`.

- Set `HTTP_PROXY` and `HTTPS_PROXY` for package downloads, native HTTP requests, Observe and the optional OTLP exporter. Use `NO_PROXY` for hosts you reach directly. Plain HTTP uses proxy forwarding and HTTPS uses a CONNECT tunnel. On Linux, install a private CA in the system trust store or point `SSL_CERT_FILE` to a trusted CA bundle. Rust programs that used the old Hew connector for package registry operations can use `hew_pkg::client::RegistryClient`.

- The optional component host uses a patched Wasmtime release. Compiled Hew reactor components now receive the stack space required for fault recovery.

- The SMTP library has been updated to address six published advisories.

## Learn from complete programs

The [language guide](../hew-language-guide.md) uses a JSON order reader that reports bad input, a bounded batch that reuses the
reader, and a supervised worker that recovers while its siblings retain state.
The supervisor example can wait for you to start an Observe recording before
triggering the fault.

## Inspect actor failures

Observe clients can recover the actor’s crash message, handler and source
location from a live report or a saved recording when the producer supplies
them. Older recordings remain readable. Lifecycle events with no handler
information no longer display the actor’s first handler.

## Run interactive programs

`hew run` now gives interactive programs access to the terminal and forwards the program’s exit code or signal to the shell. Ctrl-C stops the program and the `hew run` invocation. `hew run`, `hew debug` and `hew eval` remove their own temporary build directories after normal exits, failures and handled termination.

## Building Hew from source

Windows developer builds preserve drive-qualified and UNC Cargo target directories. The staged compiler now has its `.exe` extension, so you can launch it directly from Command Prompt or PowerShell.

## Link to a shared runtime

Use `hew build --link=dynamic` or `hew run --link=dynamic` on Linux (glibc), FreeBSD and macOS to share Hew’s runtime library across programs. Runtime filenames include the Hew release version, so programs can keep using the library they were built with after an upgrade. Static linking stays the default.

On Debian and RPM systems, a machine that only runs your dynamically linked program can install `libhew0.11.1` on its own. See [linking Hew programs](../linking.md) for runtime search paths and packaging.

## Performance and profiling

- Matching a borrowed recursive enum reuses its storage. In a native traversal of a 1,024-node tree, allocator calls fell from 22,609 to 2,104. Each local actor request also saves one allocation.

- When reporting a native fault, Hew now checks function addresses before decoding names and source locations. This reduces the work needed to produce a stack trace when a supervised worker repeatedly fails.

- The native compiler now uses LLVM 23.1.6. If you build Hew from source, follow the [build guide](../cross-platform-build-guide.md) for your platform. Prebuilt SDKs include the compiler backend.

- Programs that construct large owning tuples compile faster. On the measured Linux machine, checking a 2,048-field tuple fell from 8.62 seconds to 2.64 seconds.

- Unicode indexing uses existing UTF-8 checkpoints more efficiently. In an LLVM 22 comparison during development, the word-frequency example used 11.8% fewer instructions on the measured mixed-text corpus.

- To profile an optimized program with Hew source locations, build it with `hew build -g --opt-level 2 microgpt.hew`, then run `samply record ./microgpt`. On Linux, Hew prefers debug tools matching its LLVM version and keeps the original debug information if rewriting would lose a checked source location.
