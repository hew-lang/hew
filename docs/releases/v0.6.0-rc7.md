# Hew v0.6.0-rc7

Hew v0.6.0-rc7 gives errors and data a common foundation, adds a readiness
reactor with blocking-call offload, and makes standard input a waiting call. It
also replaces `unwrap_or` with `??` and `handle`, and ships npm packages with
provenance from one tag-triggered release pipeline. Existing rc4 and rc5
programs need a source migration; the table below lists every spelling that
changed.

rc6 reached GitHub, the container registry and Homebrew without its npm
packages, because the publish step named the tarball by a bare path. rc7 is the
first release to publish `@hew-lang/wasm` and `@hew-lang/sandbox-vm`.

## Errors and data

Errors convert at the failure edge by one rule, `fails E` is the single spelling
of a fallible function (a unit fallible function writes `fails E` with no
result), and `Result.context` attaches a description to errors that describe
themselves. Literals are sized by the error type at `return error`.

`hew-codec` plans every data type once and walks it for each format.
`format.encode` and `format.decode` replace the older wire calls, report a typed
`DecodeError`, and flag repeated keys and set elements as `Duplicate`. Text keys
use `#[serial]`, and wire variants are tagged explicitly.

## Local recovery

`optional ?? fallback` supplies a fallback only when an `Option` is absent.
`result handle problem { recovery }` runs its block only on an error, with the
error bound to a name you choose. Neither converts runtime faults or
cancellation into values. The old `unwrap_or` family is gone.

## Concurrency and input

The runtime reactor reports readiness only; system calls run on the worker that
asked for them. `#[offload]` runs a blocking `extern` call on a separate pool so
actors keep running, and a program ends without waiting for an abandoned
offload. Standard output and error share one ordered queue.

`io.read_line()` waits for input without blocking other actors and returns
`None` at end of input. The browser VM serves the same line reads. Reads from
`/dev/null` work on macOS, and concurrent reads queue instead of racing.

## Traits and generics

Trait identity is by declaration, so a user trait with a familiar name cannot
acquire compiler behaviour. Static calls, associated functions and conversions
run through a generic binder's bound, and the call's arguments choose the bound
when several apply. Trait objects fill their slots from the layout, render
through `Display` when the trait closure has it, and suspend only through a
slot declared `fn[suspends]`.

A contextual variant such as `.Some` or `.Err` takes its type from a typed
sibling branch, so `if` and `match` arms no longer need every arm to repeat the
owner.

## Tooling

`hew fmt --migrate` previews its edits, honours exclusions, writes safely and
respells bare variants. The formatter prints a range tight when both operands
are atoms. Native executables embed the compiler's provenance so a binary can
report which build produced it.

Directory modules check, test and analyse in the editor as a whole module. macOS
executables link with the system linker.

## Release pipeline

One pipeline runs from a signed `v*` tag: it builds every archive, package,
image and npm tarball once, then publishes them all. `@hew-lang/wasm` and
`@hew-lang/sandbox-vm` publish to npmjs with provenance, with GitHub Packages
as a mirror. A single approval of the `release` environment releases every
external destination. Cargo and npm dependencies are refreshed, and dependency
policy now runs on every pull request.

## BREAKING

Run `hew fmt --migrate --root .` for the mechanical spellings, then review the
result.

| Before                                        | Now                                                                                |
| --------------------------------------------- | ---------------------------------------------------------------------------------- |
| `opt.unwrap_or(x)`, `opt.unwrap_or_str(x)`    | `opt ?? x`                                                                         |
| `result.unwrap_or(x)`                         | `result handle e { x }`                                                            |
| bare `Ok(v)`, `Err(e)`, `Some(v)`, `None`     | `.Ok(v)`, `.Err(e)`, `.Some(v)`, `.None`                                           |
| `option.unwrap_or_str`                        | removed; use `??`                                                                  |
| `RunLifecycleEvent` (machine events)          | `RunLifecycle.Event`                                                               |
| `fn f(p: Point, q: Point)` called as `p.f(q)` | an associated function: call `Point.f(p, q)`, or declare `self` to keep the method |
| `io.read_line() -> string`                    | `io.read_line() -> Option<string>`; `None` at end of input                         |

A function whose first parameter is named rather than `self` never reaches a dot
call, and the compiler suggests adding a `self` receiver.

## Candidate scope

This is a release candidate, with further v0.6 work still planned. Browser
execution uses the shared frontend and ownership pipeline but has a defined
capability subset; native-only operations are reported explicitly, and refusal
does not count as successful execution.

See [browser runtime behaviour and limits](https://github.com/hew-lang/hew/blob/v0.6.0-rc7/docs/sandbox-vm-divergences.md) for the
current browser capabilities, and the [language guide](https://github.com/hew-lang/hew/blob/v0.6.0-rc7/docs/hew-language-guide.md)
for source migration and everyday APIs.
