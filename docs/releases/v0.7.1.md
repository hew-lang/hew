# Hew 0.7.1

WebSocket text and binary sends observe scope deadlines and cancellation while
a peer is slow or has stopped reading. The ordinary `Conn.send_text` and
`Conn.send_binary` APIs use the same native I/O ownership and readiness machinery
as other socket operations.

An interrupted write closes its connection, including when part of a frame may
already have reached the peer. Applications receive the existing network error
or scope recovery result and decide whether to reconnect; messages are not
replayed automatically. Other connections continue independently.

Upgrade native WebSocket services that need bounded writes or prompt shutdown
with connected clients. Existing source calls retain their spelling.
