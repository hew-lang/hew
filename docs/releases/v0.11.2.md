# Hew 0.11.2

Hew adds module-private fields on named records, expands `std.cache` and `std.random`, removes superseded top-level compiler aliases and speeds up both native release compilation and runtime execution.

## Language and tooling

- Named records support module-private fields. Private field access is enforced at the declaring module, including in projected record constructors, and respected in editor completions, hover documentation and syntax highlighting.

- Top-level `hew compile` and `hew playground verify` have been removed. Use `hew build` to produce an executable, replace `hew compile` with `hew tool compile` (same arguments; bare `hew file.hew` keeps its existing artifact paths) and replace `hew playground verify` with `hew tool playground-verify`.

- The formatter preserves source grouping, macro input and comments more faithfully.

- Editor and LSP tooling colour contextual failure syntax, end import folding spans at their semicolon and reuse document line offsets and test source snapshots to reduce repeated work.

## Standard library and codecs

- `std.cache.Cache` fields are now module-private. Migrate direct field reads and writes to `capacity()`, `ttl()` and `set_limits(capacity, ttl)`. `std.cache` also adds `touch(key)`, `eviction: .Lru` for least-recently-used eviction, faster pruning that avoids scanning live entries and `cache:` prefixes on `CacheError` display messages.

- `std.stream` resumes newline scans across chunked input instead of rescanning buffered bytes from the start.

- `std.random` runs weighted draws in Hew across both native and browser targets.

- `Arena.contains` and `Arena.remove` no longer require `T: Clone`. Standard library fixes also move owned vector elements without cloning, preserve numeric errors at representation limits and preserve UTF-8 byte and scalar boundaries in HTTP and streams.

- `std.text.markdown` and `hew doc` (vendored `pulldown-cmark`) normalize empty Markdown heading ranges so callers trim heading spans safely.

- YAML decoding preserves indentation in multiline strings.

- Live tooling includes a portable vibration monitor built with generated services.

## Performance and runtime reliability

- Large static `--release` builds (or `--opt-level 2` without `-g`) on Linux x86-64 (glibc) can generate native objects in parallel when sufficient CPU and memory headroom, `ld.lld` and `llvm-objcopy` or `objcopy` are available. Hew verifies linked source ranges before using the split object.

- Native code generation places repeated owned child frames in their parent, omits unused coroutine root storage and empty actor request visitors, reduces coroutine cleanup code, skips heap acquisition for values without backing and records authored function names in DWARF for split-coroutine frames.

- Ownership verification and type checking share CFG, cleanup, ancestry and dependency state across walks and reuse ownership proofs for wide aggregates.

- Runtime improvements refund a single backing without a temporary map, acquire shared copy backing once, skip empty static callable release walks, retain gossip intent until send, keep the first reply waiter inline and skip cycle scans for actor waits with an escape.

- Unrecovered supervised crash counts are verified consistently across native and WASI execution, and unstarted remote sends keep blocking sends queued or report local capacity and shutdown errors when another worker cannot start.

## Security, documentation and builds

- Updated `url` to `2.5.9` to address `RUSTSEC-2026-0592` (nested `blob:` URL stack overflow in `Url::origin()`) and aligned `regex` `1.13.2` across Hew and its fuzz targets.

- Core examples and language documentation have been refreshed with focused, runnable programs and updated module import guidance.

- Native runtime builds use distinct Cargo outputs to avoid Windows artifact collisions, and CLI documentation describes Windows foreground console interrupt behaviour and forced termination of macOS runs.
