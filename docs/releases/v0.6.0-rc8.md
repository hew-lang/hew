# Hew v0.6.0-rc8

This candidate brings native suspension, structured tasks and typed failure
edges together. It also updates package imports, keyed construction and the
registry client. Existing programs need source migration and native libraries
must be rebuilt against the matching toolchain.

## Tasks and suspension

Native suspending functions lower from physical MIR to explicit frame states
and resume switches. Sequential child calls reuse storage after the previous
child has been destroyed. Synchronous callable cleanup uses the ordinary drop
path without allocating a continuation frame.

Ordinary calls wait. `fork` starts concurrent work and `await` joins it:

```hew
fn square(value: i64) -> i64 {
    sleep(2ms);
    value * value
}

fn main() {
    let pending = fork square(3);
    println(await pending);

    let results = await fork [square(4), square(5)];
    for result in results { println(result); }

    let first = race [square(6), square(7)];
    println("other work");
    println(await first);
}
```

`race [...]` accepts calls or existing task handles and produces a task. It
cancels and drains losing work before publishing the first result. An ordinary
`Err` can win; use `await race [...]?` to propagate the awaited error from a
function declaring `fails E`. `select` retains its distinct behaviour:
unselected task handles continue running. Batch fork also accepts tuples when
the results have different types.

Task lifetime checks follow values through patterns, aggregates, callbacks and
generic calls. Completed origin queries share exact argument environments,
avoiding repeated expansion in larger projects.

## Source and errors

- Keyed construction uses braces: `spawn Worker { id: 1 }`. A construction
  without keys is `spawn Worker`. Supervisor children and machine transition
  heads use the same brace convention.
- A typed local may defer initialization, as in `let answer: i64;`, provided
  every path assigns it before use. Actor initialization follows the same
  definite-assignment rules.
- Functions that propagate with `?` declare `fails E`. Standard-library
  failures carry typed errors, including process exit status and networking
  cancellation. Review error matches after mechanical migration.
- Nested record variants in payloads, such as `.Err(.Io { path, cause })`,
  use the same pattern rules as direct variants.

Package membership and imports are anchored to the nearest `hew.toml`.
Imports inside a package can resolve from its root; a sibling/root ambiguity
is diagnosed. Standard-library discovery remains tied to the compiler's
toolchain layout, including when a running executable is replaced.

## I/O and ownership

Socket and child-pipe `try_send` do nonblocking writes. An accepted partial
write keeps its remainder in the sink and flushes it before the next item;
`Full` means no bytes were accepted. Timeout progress counts bytes from the
current item. Normal sink completion drains accepted data.

Pipes and stream adapters support owned elements, including local actor
handles and empty values. Resource cleanup remains at scope exit, actor
teardown retains its owner through reentrant hooks, and zero-sized values
require no memory loads or stores.

## Migration and packages

Run `hew fmt --migrate --root .`, then review and check the result. Resolve
package dependencies before checker-backed migration. The
[v0.6 migration guide](../migrations/v0.6.0.md) describes the changed surfaces.

The registry client recognizes official slash wire identities and custom
registry identity modes while retaining signature checks. Compatible signed
ecosystem archives require separate qualification and publication; a corrected
client does not update source inside older archives.

Editor renames use checked binding identities. The bundled Sublime grammar
recognizes current task syntax and treats retired `join` as an ordinary name.

This remains a release candidate. Native execution and supported sandbox
operations share language semantics; native-only capabilities retain their
documented restrictions. See the [capability matrix](../wasm-capability-matrix.md)
for sandbox support.
