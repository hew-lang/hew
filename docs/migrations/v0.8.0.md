# Migrating to Hew 0.8

Edition 2026 stays unchanged. Update the compiler and its bundled standard
library together. Packages using these features should require Hew 0.8.0 or
newer in `hew.toml`.

## Inferred captures

Replace `capture(var count) |value| { ... }` with `|value| { ... }`. Writes infer
private mutable captured storage. The surrounding binding remains unchanged;
declare the closure binding `var` when invocation mutates its environment.
Remove explicit closure parameter, result and generic annotations when inference
provides the intended contract; useful public callable annotations remain valid.

## Machine results and limits

Machine `step(event)` now returns a typed result. Handle it with `match`, `?` or
`expect` according to the caller's failure policy. Replace
`step_with_limit(event, count)` with `step(event, limit: count)`. Both forms use
the same rollback behaviour. `std.machine.watch.Owner.step(event)` continues to
return its report directly.

## Typed timeouts

Replace unitless integer arguments to duration-taking APIs with explicit units.
For example, an old millisecond timeout of `5000` becomes `5s`, and a timeout of
`250` becomes `250ms`. Check the old API's scale before converting. Use explicit
duration conversion methods at foreign or protocol boundaries. Decimal literals
such as `0.25s` are exact; a literal requiring fractional nanoseconds is rejected.

## Semaphore leases

Prefer `let lease = sem.lease();` for scoped capacity ownership. The lease
releases automatically, so remove the corresponding manual `sem.release()`.
Keep raw `acquire` and `release` for intentional signalling across tasks. Share a
permit count with explicit `sem.clone()`; moving an affine handle still transfers
ownership. A lease cannot be cloned or reused after closing.

## Confined functions and actors

Acquire ambient resources outside the confined boundary and pass the required
service in. A default expression that acquires ambient authority is checked when
the argument is omitted; supplying a service explicitly skips that default.
Opaque raw calls remain outside the confined contract.

## Default expressions

Declare defaults with `parameter: Type = expression`. They resolve names in the
declaration's module and cannot refer to `self` or another value parameter.
Trait implementations inherit the declaration's defaults and must not repeat
them. Foreign `extern` declarations reject source defaults. Calling a function
value uses its full callable signature, without an omitted-argument contract.
