# Hew v0.6.0-rc3

Hew v0.6.0-rc3 is a native-focused release candidate for v0.6.0. It replaces
the native compiler core, expands ownership and concurrency support, and
brings substantial changes to the language and standard library since rc2.
Existing programs will need migration.

This candidate is intended for trying real native programs and reporting
regressions. CLI WebAssembly/WASI output and native source-level debugging are
not available through the new compiler core yet. These and other remaining limits
are described below; rc3 is not the final v0.6.0 release.

## Highlights

### A new native compiler core

Native compilation now follows one path through HIR, ownership SIR, physical
MIR and LLVM. SIR makes ownership transfers, borrowing and cleanup explicit;
MIR turns those checked operations into storage layouts and native calls. The
previous native lowering implementation has been removed.

For Hew programs, this means broader support for values that own other values:
nested records and tuples, enum payloads, fixed arrays, captured closures,
trait objects, resources and linear values. Destructuring can move selected
fields while preserving their siblings. Cleanup also accounts for partially
initialized values and failures during evaluation.

Nested collection assignments such as `rows[i].values[key][j] += text` now
preserve value semantics, including updates through actor state and mutable
captures. Independent copies keep their previous values. Native C interop
also carries explicit ownership contracts for arguments, results and opaque
resource handles.

### Calls, tasks and actors work together

An ordinary call waits for its result, including an actor handler or a
suspending I/O operation. `fork` starts concurrent work, and `await` joins a
task or a vector of tasks. Scopes can return values, apply deadlines and
recover faults after child work and resource cleanup settle.

Actor calls return typed results. Mailbox views provide one-way submission;
policy views choose admission behaviour for completion calls. Rejected
requests retain their payload so a program can retry them or redirect them
to another actor. `select` supports tasks, actor calls, channel receives and
timers.

Native supervision supports restart-aware child handles, nested supervisors,
static pools, lifecycle hooks, local links and monitors, and cooperative
shutdown. A supervised child handle resolves the current incarnation after a
restart. `close(actor)` requests shutdown, and `closed(actor)` observes it.

### Text and library improvements

Strings preserve complete UTF-8 contents, including embedded NUL characters,
through native execution and managed-value calls. String indexing, slicing
and iteration operate on codepoints. Byte decoding is explicit, with both
fallible and lossy UTF-8 conversion.

Owning JSON and YAML values receive automatic cleanup. Numeric APIs include
checked, wrapping and saturating arithmetic, bit operations and additional
mathematical functions. Random APIs provide seeded generators and secure
entropy helpers. Machines gain typed step reports and outputs, generic and
constant parameters, entry/exit hooks and one level of composite states.

Project tooling gains `hew new`, clearer command help and build outputs under
`target/<profile>`. Explicit `-o` paths work for both file and manifest builds.
Package commands honour `HEW_HOME` and `HEW_REGISTRY`, reject malformed
manifests and unknown packages, and provide dry-run support.

## Breaking changes and migration

### Declarations and patterns

- Declare records with `type`, replacing `record`. Use commas between
  structural members: `type Point { x: i64, y: i64, }`.
- Use dotted enum variants in expressions and patterns: `.Ready` or
  `Status.Ready`. Matches must cover every possible input, or include a
  fallback arm.
- An actor's name is the type of its handle. Replace `Pid<Worker>` and
  `LocalPid<Worker>` with `Worker`. Supervised children use `ChildRef<Worker>`;
  remote node handles still use `RemotePid<Worker>`.
- Machine transitions read the current value through `state`. Write a
  transition as `on Open(user): Idle => Live { user: user }` and a fallback
  as `default { state }`.

### Concurrency and results

- Actor calls wait for completion, including handlers returning unit. Handle
  their `Result` with `?`, `match`, `handle` or an explicit `let _ =` when the
  outcome is intentionally discarded.
- Replace the former send, join and actor-await forms with ordinary calls,
  `fork`, task `await` and mailbox views. For example,
  `mailbox(worker, on_full: .Reject).run()` submits a request, while
  `policy(worker, on_full: .Reject).run()` waits for completion with rejecting
  admission.
- Use `scope within duration { ... }` for a deadline. Selection arms use
  `value from source => body`; timer arms use `after duration => body`.
- Fallible library operations use their ordinary names and return `Result`.
  For example, `fs.try_read(path)` becomes `fs.read(path)`, and callers of the
  former bare-string `fs.read` must handle its result. Nonblocking operations
  such as `channel.try_recv` retain their distinct names.
- Replace parameterless `unwrap()` with `expect("reason")`, or handle the
  failure. Environment lookup returns `Option<string>`.

### Ownership, text and interop

- Resource cleanup is `fn close(consume self)` returning unit. Keep fallible
  finish or commit operations separate from cleanup. JSON values need neither
  manual `free` nor `close`.
- Mutable captured state is explicit: `capture(var count) || ...`. Callable
  types express capabilities with forms such as `fn[var]`, `fn[once]` and
  `fn[suspends]`.
- `Vec.get` requires an element that can be copied. Use borrowed indexing or
  iteration to inspect a resource-bearing element, or consuming iteration to
  transfer ownership. Unconsumed linear values remain compile errors.
- Decode bytes with `std.encoding.utf8.decode` or `decode_lossy`. Import
  `std.math` and `std.random` explicitly. Import directory modules by their
  directory name rather than their entry-file spelling.
- An `optional` wire field must have type `Option<T>`. A missing key and a
  present null value are distinct; required fields must be present.
- Rebuild native libraries and embedding integrations with the matching rc3
  compiler, runtime and standard library. Internal IR and runtime interfaces
  have changed. Physical MIR inspection is available through
  `hew tool compile --dump-mir physical`.

The formatter's `hew fmt --migrate --root .` command can help with mechanical
syntax changes. Review the result and update behavioural changes explicitly.
The [language guide](https://github.com/hew-lang/hew/blob/v0.6.0-rc3/docs/hew-language-guide.md)
and [standard-library sources](https://github.com/hew-lang/hew/tree/v0.6.0-rc3/std)
describe the current interfaces.

## Known limitations

- **CLI WebAssembly/WASI output is unavailable on the new compiler path.** The
  browser analysis package and educational sandbox support their own subset;
  they do not provide full native-language parity. Follow
  [#3368](https://github.com/hew-lang/hew/issues/3368).
- **Native debug metadata is unavailable.** `hew build -g` and `hew debug`
  cannot produce a source-debuggable program on this path. Follow
  [#3369](https://github.com/hew-lang/hew/issues/3369).
- **Some native combinations remain incomplete.** Known failures include
  distributed actor operations and some resource, generator and shutdown
  combinations. Passing native acceptance does not imply that every language
  feature or every combination is complete.
- Consuming a non-copyable actor-state field, including iterating a stored
  `Stream`, is currently rejected. Iterating an actor generator's returned
  stream is supported.
- Mailbox coalescing and supervisor `wired_to` sibling wiring are not yet
  supported by native lowering. Supervisor pool sizes must be literals.
  Stream reads cannot be used directly as `select` sources.
- Composite machines support one nesting level. Resource-identity payloads
  remain outside pure machine state; local `Rc`/`Weak` handles do not become
  transferable between actors.
- **Windows programs cannot glob, and a deferred actor stop does not link.**
  `std.os` glob expansion is unimplemented there
  ([#3412](https://github.com/hew-lang/hew/issues/3412)), and an actor that
  defers its stop links against POSIX `usleep`
  ([#3413](https://github.com/hew-lang/hew/issues/3413)).
- **A restarted nested supervisor role can be unreachable under load.** A call
  that follows `await_restart` on a nested supervisor can run before the
  restart lands, because the barrier gives up on a wall-clock window. Every
  platform is affected; a loaded or slow host shows it most. Measured at
  roughly five occurrences in fifteen hundred runs on a saturated Linux host.
  Follow [#3417](https://github.com/hew-lang/hew/issues/3417) and
  [#3419](https://github.com/hew-lang/hew/issues/3419).

For this candidate, regression testing accepts the existing, individually
recorded expected failures while rejecting new failures. Native acceptance,
sanitizer checks and packaged-binary smoke tests remain release requirements.
Native acceptance qualifies Linux x86_64, Linux aarch64 and FreeBSD x86_64.
The Windows and macOS archives are built and their Rust and C-ABI suites
pass, but the gaps above leave their acceptance corpus unqualified for this
candidate.

## Downloads

The release archives contain the compiler, language server, actor observer,
runtime libraries, standard-library sources and shell completions. Choose the
archive for Linux, macOS or FreeBSD on x86_64 or aarch64, or Windows on x86_64,
and verify it against `hew-v0.6.0-rc3-checksums.txt`.

The existing hosted playground remains on its previous compiler while its
execution capabilities are updated for rc3. npm packages are published
separately under the `next` prerelease channel.

Please include `hew version`, the target platform and a small reproducer when
[reporting a problem](https://github.com/hew-lang/hew/issues).
