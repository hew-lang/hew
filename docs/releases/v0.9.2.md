# Hew 0.9.2

Hew 0.9.2 fixes standard-library directory imports in the browser compiler.

When sources were embedded without a filesystem, relative standard-library roots
used a different path spelling from their source documents. Directory modules
could then lose their private peer files. For example, importing
`std.net.http.codec` reported undefined parsing helpers.

Standard-library roots now use the same source-path normalization as their
embedded documents. Both single-source and project compilation resolve the
module and its peers together. Regression coverage compiles and executes an HTTP
response parser through both browser APIs, using both the module entry and its
peer import.
