# Hew 0.7.0

Hew 0.7 brings JSON, TOML and YAML document processing to the sandbox through
the same parsing and formatting engines used by native programs. It continues
language edition 2026.

## Encoding values on native and browser hosts

The ordinary `std.encoding.json`, `std.encoding.toml` and `std.encoding.yaml`
value APIs execute in the sandbox. Copies own independent values; checked
access, mutation, equality and cleanup follow the native behaviour. Values retain
full-width JSON integers and numeric kinds, YAML mapping keys, order and tags,
and TOML datetimes. Parser errors stay local to their actor and format.

Browser hosts pair matching `@hew-lang/wasm` and `@hew-lang/sandbox-vm` versions
and pass the initialized `executeCodec` export as `runBytecode`'s `codecBridge`
option. This is the same bridge used for typed serialization. The
[sandbox host instructions](../../hew-sandbox-vm/README.md#validation) describe
initialization and the shared calendar bridge.

## Bounded hostname resolution

QUIC hostname resolution observes connection and listener deadlines. Resolution
work shares a bounded budget across node lifetimes, including cancellation and
node recreation. Numeric addresses retain their direct connection path.
