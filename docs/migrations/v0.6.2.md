# Migrating to Hew v0.6.2

These changes are under development for the release after v0.6.1. They are
not present in the v0.6.0 or v0.6.1 SDKs.

## Strings and Unicode scalars

String lengths, positions and ranges count Unicode scalars. Replace the
following spellings; the new SDK removes their aliases.

| Previous                                                     | Replacement                                                                  |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| `s.char_at(i)`                                               | `s.get(i)` returning `Option<char>`                                          |
| `s.char_count_utf8()`                                        | `s.len()`                                                                    |
| `s.codepoint_at_utf8(i)`                                     | `s.get(i).map(\|c: char\| c.as_i64())`                                       |
| `s.slice(start, end)`                                        | `s[start..end]`, or `s.get(start..end)` for `Option<string>`                 |
| `s.chars()` returning `Vec<char>`                            | `s.iter()`; collect it when a vector is required                             |
| String classification methods                                | Classify each `char` with `is_digit()`, `is_letter()` or `is_alphanumeric()` |
| `string.from_int(n)`, `from_float(n)`, `from_bool(b)`        | `f"{n}"`, `f"{b}"`                                                           |
| `string.from_char(code)`                                     | `code.try_to_char()`, then format the resulting `char`                       |
| `string.repeat(s, n)`, `string.trim(s)` and other free twins | `s.repeat(n)`, `s.trim()` and the corresponding methods                      |
| `string.join(parts, sep)`                                    | `parts.join(sep)`                                                            |
| `std.text.unicode` classification and case helpers           | `char` methods such as `is_letter()`, `is_whitespace()` and `to_upper()`     |
| `unicode.codepoint_at(s, i)`, `unicode.rune_len(code)`       | `s.get(i)` and `code.try_to_char().map(\|c: char\| c.len_utf8())`            |

Import `std.iter` to collect an iterator with `iter.collect(s.iter())`.
Iteration reads a snapshot without creating a vector. `s.first()` and
`s.last()` return optional endpoints; `find_from(needle, start)` searches from
a scalar position. Use `s += suffix` to append text and `s.push(c)` to append
a scalar. Existing copies retain their values after mutation.

Ranges no longer clamp endpoints. Invalid direct indexing or ranges raise a
bounds fault; `get` returns `None`. Strings do not support index assignment.
`is_digit()` recognizes ASCII digits; `is_letter()` recognizes Unicode letters,
and `is_alphanumeric()` combines those two sets. Case conversion returns one
scalar, preserving the input when full conversion would require several.

Replace integer `as char` casts with `try_to_char()`, which returns `None` for
negative values, surrogates and values above U+10FFFF. Use `c.as_u32()` or
`c.as_i64()` for a lossless scalar number; narrowing casts to 8-bit or 16-bit
integers are refused. `c.to_digit(radix)` returns an optional digit value.

Rebuild native libraries that exchange managed Hew strings against the matching
SDK: the string storage layout has changed.

## Generic sorting

Replace `sort.sort_ints`, `sort_strings` and `sort_floats` with `sort.sort<T: Ord>`
or `sort.sort_by`. Replace the corresponding reverse helpers with `sort.reverse<T>`.
The counted sorting helpers are removed; a mutable comparator can keep its own
comparison count.

Floating-point values remain outside `Ord`. For their total IEEE ordering, use
`sort.sort_by(values, |a, b| math.total_cmp(a, b) < 0)` after importing `std.math`
and `std.sort`.
