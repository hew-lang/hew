# Wall-clock ceiling for `hew check` on tests/compile-measure/mir-lowering-shape.hew,
# scored as the fastest of three runs (see scripts/bench-mir.sh).
#
# Where the number comes from: on the machine this was set on, the fixture took
# 4383 ms before the redundant whole-function derivations were removed and
# settles near 700 ms after, drifting to about 900 ms with a dozen other builds
# running. The ceiling is a little over twice the settled figure: a loaded
# runner stays well inside it, and a return to per-block CFG replay or to a
# dominator fixpoint over an unordered set blows through it several times over.
#
# SHORTCUT. WHY: a wall-clock ceiling is a proxy for the real invariant, which
# is that MIR lowering cost is proportional to function size; nothing in the
# tree can assert that shape directly, so a machine-dependent number stands in
# for it. WHEN obsolete: when the ownership replay is a single incremental
# analysis whose visit count can be asserted (a counter of block visits per
# function, compared against block count), this file is replaced by that
# behavioural assertion. WHAT the real fix is: assert the complexity, not the
# clock — one replay per pass, no replay inside a per-block loop.
#
# Ratchet: lower this manually after a measured, reviewed improvement. Never
# raise it to make a red gate pass; a regression here is the gate working.
check_wall_ms_ceiling=1500
