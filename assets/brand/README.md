# Hew blue jay

`hew-bluejay.svg` is the canonical Hew mark: the front-facing blue jay recovered from the September 8 identity work. Keep its face and silhouette unchanged.

The adjacent files are supplied treatments of the same mark:

- `hew-bluejay-dark.svg` — brighter treatment for dark surfaces
- `hew-bluejay-four-colour.svg` — strict four-colour treatment
- `hew-bluejay-app-icon.svg` — composed 512 px app-icon source

Downstream repositories should copy one of these supplied sources and record this path and the source commit. Do not regenerate the mark from the older long-bodied or faceted bird assets.
