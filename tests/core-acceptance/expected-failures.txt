# expected-failures.txt — the one expected-failure ledger for the core
# acceptance runner (`make core-acceptance`).
#
# One row per case per platform: `<platforms>\t<id>  # <reason>`, where
# <platforms> is a comma-separated list of linux, macos, windows, freebsd (a
# row that applies everywhere spells all four; there is no wildcard). The
# runner applies a row only on its named platforms, refuses a row naming a
# case that no longer exists, refuses two rows selecting the same case on
# the same platform, and refuses a row naming a case that now passes on that
# platform: ratchets only shrink. A case that fails without a matching row
# is red.
#
# A doc fence's id is <prefix>-<cksum of the fence's own text>, so editing
# an unrelated fence never relabels the ones around it and a fence whose
# text changes arrives as a new case.
