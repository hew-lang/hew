# Hew v0.6.1

This release adds compile-time typed data, source locations, contextual macros,
declared source generation, generic closures, deeper machine hierarchies and
associated-type projection bounds to the 0.6 line. It also adds actor
interceptors, cross-package trait coherence and construction-centred confinement.
Packages using these features can declare `hew = ">=0.6.1"` in `hew.toml`.

`embed!(path)` reads JSON, YAML or TOML at compile time and checks it against the
expected concrete type and its ordinary serialization schema. Generated programs
construct ordinary values without decoding the file at runtime. Repeated uses
retain independent value semantics. Invalid data names its input file and field
path; embedded collection keys with custom equality are rejected.

`location!()` produces an ordinary `SourceLocation` constant. Ordinary constants
also support records, enums, tuples and collections, including record updates
and vector spreads, through the same checked value representation.

Actor interceptor chains preserve caller identity, refusal and cleanup
behaviour. A refused call has no response value.

Native and sandbox execution share compile-time data semantics, including target-specific
integer range checks.

Trait implementations obey shared package ownership and overlap rules across
native compilation, virtual package inputs and editor analysis. Generic and
blanket implementations use the same checked declaration identities.

Generic closures declare binders after the opening pipe, as in
`|<T: Eq> left: T, right: T| -> bool { left == right }`. Quantified callable types
use `fn[qualifiers]<T: Bound>(T) -> R`. Calls infer concrete types or accept an
explicit type list. All instantiations share the same captured state; mutable
and once-only invocation rules apply across the whole closure value. The retired
`<T>(params) => body` spelling remains invalid.

Generic functions can constrain associated-type projections with
`where I.Item: Display` or `where <I as Iterator>.Item: Display`. These bounds
carry through imported helpers and generic closures on native and sandbox
execution, including equalities such as `Iterator<Item = T>`.

Composite machines support deeper nesting and recursive initial-child descent.
Child rules precede the nearest ancestor's rules, with guarded fallback. Named
transitions retain shared ancestors and run hooks only along the changed branch.
Computed `_` targets exit the full active branch before evaluating the body once,
then enter the returned branch, including same-leaf and sibling returns. Existing
computed transitions that depend on skipping compound hooks should use named
targets. Parallel regions and history states remain unavailable.

Distributed actor calls use wire protocol v4 with canonical dotted
declaration identities and inherited request budgets. Earlier protocol versions
are rejected explicitly; there is no
numeric handler-hash fallback. Upgrade communicating peers together. Shared
protocol declarations should live in imported modules with portable dotted
owner paths, rather than separate executable roots.

Declarative macros preserve definition and caller binding contexts across native
and sandbox compilation. Function and method attribute macros compose in stacks;
the CLI, editor and browser analyzer use the same expansion pipeline. Declared
generators run through `hew generate`, with tracked inputs and check mode.

Native coroutine lowering uses LLVM's switched-resume machinery for frame
splitting and optimization. Proven synchronous callables avoid child coroutine
states; implicit resource cleanup participates in source suspension effects.
Scalar vector replacement and last-use actor payload transfers avoid redundant
allocation and reference-count work.

Inbound distributed actor asks wait through scheduler readiness instead of one
blocked OS thread per request. Pending replies are bounded per destination actor
incarnation, so a slow service does not occupy unrelated services' ask capacity.

Actor completion calls inherit the earliest scope and incoming request expiry.
Expired queued calls never start. A claimed handler remains owned by its actor,
while its nested calls return `TimedOut` once the inherited budget is exhausted.
Caller expiry abandons the reply and cannot undo a remote mutation. Local native
and sandbox execution share that boundary; distributed asks carry relative
budgets and authenticated best-effort withdrawal of queued requests. Caller
expiry and cancellation remain responsive when another sender or a peer stalls
transport progress. Required ownership cleanup remains shielded from the
abandoned request deadline.

Actors and ordinary functions can use `#[confined]` to reject transitive ambient
authority acquisition and opaque native escapes. Opened `std.fs.ReadFile` and
`WriteFile` resources provide directional access to one file, supplied once at
construction. Ordinary helpers, captured callables, trait implementations and
required cleanup preserve that boundary. Incomplete authority summaries,
including erased generator execution or cleanup, are refused conservatively.
The same domain interfaces support
in-memory services on the browser VM. Native file resources and authenticated
cross-node capability delegation remain separate: this slice supplies native
file resources and refuses remote acquisition inside confinement; it does not
add a distributed service-reference protocol.
