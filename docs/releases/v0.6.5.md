# Hew v0.6.5

Hew 0.6.5 fixes browser Test compilation failing with a missing
`std.link_monitor` module. The Test action compiles `#[test]` functions against
the standard library shipped with the browser compiler, so tests can execute
without a host filesystem.

Upgrade `@hew-lang/wasm` and `@hew-lang/sandbox-vm` together to 0.6.5 in browser
applications.
