# Hew v0.6.3

Hew 0.6.3 adds typed wall-clock time, completes shared browser execution and
improves distributed actor errors, editor tools and package delivery.

## Language and standard library

- Add the nanosecond-precision `timestamp` primitive, distinct from monotonic
  `instant`, with checked calendar, formatting, codec and cron operations.
- Preserve clock runtime calls inside imported helper functions.
- Add lazy Map insertion and value updates through ordinary Hew methods.
- Add per-child environment and working-directory options to process execution.
- Require ordinary type methods to be declared in `impl` blocks. Inline methods
  receive a diagnostic explaining the supported spelling.
- Preserve imports that provide public methods through a library facade while
  continuing to diagnose unrelated unused imports.

## Actors and execution

- Execute actor supervision, links and monitors through the shared WASI
  lifecycle implementation, including startup failure and cancellation cleanup.
- Return typed route errors for oversized remote requests and responses while
  preserving unrelated pending calls and the connection.
- Generate membership, registry, service-offer and terminal control records from
  Hew wire types through the shared codec.
- Keep queued membership events and reconnect attempts tied to their captured
  peer publications, preserving newer connections and pending operations.
- Validate sandbox packages with the generated bytecode schema and shared
  instruction contract before execution.

## Compiler, editor and delivery tools

- Expose the shared browser project compiler for applications with multiple
  source files and supplied libraries.
- Carry structured diagnostic fixes through CLI, editor and browser consumers;
  complete type and implementation navigation, highlights, selection ranges
  and pull diagnostics.
- Publish native package archives through the workspace plan and preserve
  explicit provenance for local publications.
- Compare exact package artifacts when resuming publication and record terminal
  Homebrew delivery.
- Generate compiler metadata in the invoked checkout when sharing build targets.
- Require Linux x86_64, Linux AArch64 and browser compiler/VM artifacts for patch
  releases, and record the other platform artifacts available in each release.

## Upgrading

Use `impl` blocks for ordinary type methods and the typed datetime API for
wall-clock values. Distributed nodes use wire protocol 10; upgrade communicating
nodes together. Install matching compiler and runtime artifacts, and use the
matching browser compiler and VM packages when embedding Hew.
