# Migrating to Hew v0.6.2

These changes are under development for the release after v0.6.1. They are
not present in the v0.6.0 or v0.6.1 SDKs.

## Distributed peers and crash notifications

Upgrade communicating peers together. The wire protocol changes from v4 in
v0.6.1 to v5; peers with different protocol versions are rejected.

Replace `CrashNotification.actor_id` with a match on `CrashNotification.target`:
`.Local(id)` carries a process-local slot, and `.Remote(location)` carries the
complete remote node, slot and incarnation. Keep the full `Location` when
tracking a remote actor; a slot alone does not identify it across nodes or
restarts. The notification's `kind` still supplies its crash class.

`DownNotification.target` uses the same enum. Code that names the enum
explicitly should import `DownTarget` from `std.failure`, its new owning module.

Replace `CrashInfo.code` with `CrashInfo.kind`, a `CrashKind` value. Match public
classes such as `.Fault`, `.HeapExceeded` and `.HandlerFailed` instead of integer
runtime fault codes. `HandlerFailed` means a mailbox handler returned a declared
error without a waiting caller. `CrashInfo.message` remains the owned diagnostic
text supplied to the crash hook.

## Actor-owned one-shot timers

Actor-owned one-shot timers use `mailbox(self, after: delay).handler(args)` and
return a `Timer` cancellation handle. Dropping the handle keeps the timer;
`cancel()` before firing prevents delivery, and after firing disarms only the
overdue check. Pending timers are cancelled when their actor stops or restarts.
Timer handles cannot cross actor boundaries. In `init` and `#[on(start)]`,
`self` names the new actor. Timer messages queue until both bodies succeed;
failed construction cancels the timers and releases their payloads before
returning the failure.

Add `overdue: limit` to fault the owner with `CrashKind.TimerOverdue` if the
handler has not started within that duration of firing. Admission discard or
later `drop_old` loss counts immediately. Without `overdue`, loss is discarded
with telemetry. Timer views accept `.Reject` and `.DropNewest`; `.Wait` is
rejected with `E_TIMER_WAIT`, and targets other than `self` with `E_TIMER_TARGET`.

## Strings and Unicode scalars

String lengths, positions and ranges count Unicode scalars. Replace the
following spellings; the new SDK removes their aliases.

| Previous                                                     | Replacement                                                                  |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| `s.char_at(i)`                                               | `s.get(i)` returning `Option<char>`                                          |
| `s.char_count_utf8()`                                        | `s.len()`                                                                    |
| `s.codepoint_at_utf8(i)`                                     | `s.get(i).map(\|c: char\| c.as_i64())`                                       |
| `s.slice(start, end)`                                        | `s[start..end]`, or `s.get(start..end)` for `Option<string>`                 |
| `s.chars()` returning `Vec<char>`                            | `s.iter()`; collect it when a vector is required                             |
| String classification methods                                | Classify each `char` with `is_digit()`, `is_letter()` or `is_alphanumeric()` |
| `string.from_int(n)`, `from_float(n)`, `from_bool(b)`        | `f"{n}"`, `f"{b}"`                                                           |
| `string.from_char(code)`                                     | `code.try_to_char()`, then format the resulting `char`                       |
| `string.repeat(s, n)`, `string.trim(s)` and other free twins | `s.repeat(n)`, `s.trim()` and the corresponding methods                      |
| `string.join(parts, sep)`                                    | `parts.join(sep)`                                                            |
| `std.text.unicode` classification and case helpers           | `char` methods such as `is_letter()`, `is_whitespace()` and `to_upper()`     |
| `unicode.codepoint_at(s, i)`, `unicode.rune_len(code)`       | `s.get(i)` and `code.try_to_char().map(\|c: char\| c.len_utf8())`            |

Import `std.iter` to collect an iterator with `iter.collect(s.iter())`.
Iteration reads a snapshot without creating a vector. `s.first()` and
`s.last()` return optional endpoints; `find_from(needle, start)` searches from
a scalar position. Use `s += suffix` to append text and `s.push(c)` to append
a scalar. Existing copies retain their values after mutation.

Ranges no longer clamp endpoints. Invalid direct indexing or ranges raise a
bounds fault; `get` returns `None`. Strings do not support index assignment.
`is_digit()` recognizes ASCII digits; `is_letter()` recognizes Unicode letters,
and `is_alphanumeric()` combines those two sets. Case conversion returns one
scalar, preserving the input when full conversion would require several.

Replace integer `as char` casts with `try_to_char()`, which returns `None` for
negative values, surrogates and values above U+10FFFF. Use `c.as_u32()` or
`c.as_i64()` for a lossless scalar number; narrowing casts to 8-bit or 16-bit
integers are refused. `c.to_digit(radix)` returns an optional digit value.

Rebuild native libraries that exchange managed Hew strings against the matching
SDK: the string storage layout has changed.

## Generic sorting

Replace `sort.sort_ints`, `sort_strings` and `sort_floats` with `sort.sort<T: Ord>`
or `sort.sort_by`. Replace the corresponding reverse helpers with `sort.reverse<T>`.
The counted sorting helpers are removed; a mutable comparator can keep its own
comparison count.

Floating-point values remain outside `Ord`. For their total IEEE ordering, use
`sort.sort_by(values, |a, b| math.total_cmp(a, b) < 0)` after importing `std.math`
and `std.sort`.

## C host components

The experimental `--export-c SOURCE=SYMBOL` selector can be repeated for ordinary
public monomorphic functions. Generated headers now expose scalar arguments and
typed opaque owners for resources and component state. Consuming opaque arguments
take owner-slot pointers and clear them at handoff, including on failure. Use the
generated typed release function for early cleanup, and release all owners before
runtime shutdown or unloading the library. Existing borrowed text inputs retain
their copy semantics. Rebuild the object, generated header and static runtime
together; this boundary remains limited to matching builds.
