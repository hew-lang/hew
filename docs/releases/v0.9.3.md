# Hew 0.9.3

Hew 0.9.3 is the adoption release for the completed 0.9 language and library
programme. It combines the features introduced in [0.8](v0.8.0.md) and
[0.9](v0.9.0.md) with fixes for ordinary collection, module and supervision code,
and a fuller language guide and API reference.

Start with the [installation guide](../../README.md#install) and the
[language guide](../hew-language-guide.md). Existing programs can follow the
[0.8 migration guide](../migrations/v0.8.0.md) and
[0.9 migration guide](../migrations/v0.9.0.md).

## Correctness fixes

- Local values take precedence over same-named modules in method calls.
- `Vec.fold` lowers through the same checked pipeline as other collection
  operations, including in the sandbox.
- Crash hooks infer variants such as `.Restart` from their declared
  `CrashAction` return type.
- A nested-supervisor stop deadline bounds its entire subtree, including
  inherited deadlines, while preserving shutdown cleanup.
- Explicit process exit works in scopes containing deferred work and retains
  the exit status and existing process-exit semantics.

The standard-library directory import correction from [0.9.2](v0.9.2.md) is
included for both browser compilation APIs.

## Documentation and distribution

The language guides and public API reference cover more complete signatures,
methods, traits and machines, with improved navigation and cross-references.
Each release includes a checksummed reference documentation archive so websites
can consume the exact documentation produced with the compiler.

Hew remains edition 2026. The compiler, native SDKs and browser compiler/VM are
published together; consumers use the matched release artifacts.
