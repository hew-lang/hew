# Hew 0.9.1

Hew 0.9.1 delivers the completed [0.9 language and standard-library
cohort](v0.9.0.md), including checked I/O and networking, composed language
lowering, deferred values, bounded pipelines and asynchronous native host calls.
Use the [0.9 migration guide](../migrations/v0.9.0.md) when updating source.

Packaged SDK validation recognizes optimized recurrences across multiple LLVM
blocks. It checks every loop member for memory operations and runtime calls,
alongside source execution and LLVM verification. Independent case failures
are collected in one run.
