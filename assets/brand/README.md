# Hew blue jay

`hew-bluejay.svg` is the canonical Hew mark: the front-facing blue jay. Keep its face and silhouette unchanged.

The adjacent files are supplied treatments of the same mark:

- `hew-bluejay-dark.svg` — brighter treatment for dark surfaces
- `hew-bluejay-four-colour.svg` — strict four-colour treatment
- `hew-bluejay-app-icon.svg` — composed 512 px app-icon source

The SVG files are the editable sources. Raster exports are delivery artifacts and must be checked visually at their actual target size.

`social-preview.png` is a ready-to-upload 1200 × 630 repository preview. GitHub does not discover that file automatically; a repository administrator must upload it in the repository's social-preview settings.
