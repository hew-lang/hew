# Generate Hew source from data

Declare source generation in `hew.toml` when a schema or other input should
produce ordinary Hew files:

```toml
[[generate]]
name = "schema"
run = "tools/schema.hew"
args = ["schema.json", "models"]
inputs = ["schema.json"]
outputs = "models"
```

`run` names a Hew source in the package, or a declared dev-dependency whose
`main` is the generator. Install dependency generators with `hew install`.
Each step owns one output directory. Input globs use package-relative paths;
steps consuming another step's generated files run after that step. Cycles and
overlapping output directories are manifest errors.

Run `hew generate` to update stale steps. `hew build`, `hew run`, `hew check`
and `hew test` also prepare stale steps before using the source. A content stamp
tracks the compiler version, arguments, source inputs, lockfile and declared
data. An unchanged step keeps its output files untouched.
Readable generator-package files are included too. Other steps' output
directories are read through declared `inputs`, so their dependencies remain
explicit.

Use `hew generate --check` in CI. It executes in scratch space, formats the
result and compares it with the existing tree. A mismatch fails without
replacing the existing output. `hew publish` performs this check and includes
generated sources in the package. Registry dependencies use their shipped
sources; installing or importing them never runs their generators. Local path
dependencies run their own declared steps.

The generator runs from the package root and receives `args` through
`std.os.args()`. It can read its own package and declared input files, and write
only its output directory. Runtime path checks resolve symlinks and redirect
writes into scratch space. Filesystem refusal uses `IoError.PermissionDenied`.
Use the declared output directory's spelling and case when writing new paths.
Argument zero is the stable string `hew generate`; declared arguments start at
index one.
Network, process, environment, user extern and native-package access are refused
before execution. Clock reads return the Unix epoch and random values use a
fixed seed. Actor work runs on the deterministic driver.
Admission also checks potentially callable methods on values and actors the
generator creates, including cleanup and formatting callbacks.

Every output must be a `.hew` file beginning with the step's marker:

```hew
// @generated by hew generate (schema) from schema.json; do not edit
```

The driver parses and formats each output before publishing the directory.
`hew fmt` leaves marked files unchanged. The editor analyses generated files
normally, warns when they are edited and offers regeneration for stale output.
Opening a project never executes a generator; the editor command is explicit.

The [JSON Schema example](../../examples/generate/jsonschema/) demonstrates
object properties, scalar types and optional fields. It generates a record,
then decodes a JSON document using that record. It intentionally supports a
small schema subset and rejects unsupported shapes.

Generators use compiler admission and runtime path checks, not an OS sandbox.
Browser and sandbox VM hosts consume supplied generated source files and never
run generators themselves.
