# Hew v0.6.0-rc4

Hew v0.6.0-rc4 updates declaration syntax, actor lifecycle operations and the
testing experience. It also fixes imported type identity, value dispatch and
actor wake-up races. Existing rc3 programs need a source migration.

## Language and actor migration

Declaration members without a body end with a semicolon. This includes record
fields, enum variants and machine events. Members with their own brace-delimited
body end at the closing brace. Commas continue to separate values and arguments.
Actor state fields explicitly use `let` or `var`.

Use dotted enum variants, including `.Some`, `.None`, `.Ok` and `.Err` when the
expected type supplies their owner. Discarding a `Result` as a statement is an
error; handle it or write `let _ = expression;` to discard it deliberately.

Actor lifecycle operations distinguish requests from observations:

- `stop(actor)` requests graceful stopping; `terminate(actor)` requests forceful
  termination. `stopped(actor)` waits for completion.
- `restarted(role)` observes a supervised role's replacement incarnation.
- Resource cleanup continues to use `close`; nodes use `shutdown`.
- Supervisor child stop budgets use `stop: duration`; `stop: 0s` replaces
  `brutal_kill`. Children stop in reverse declaration order.
- Link notifications use `#[on(link)]`, and terminal reasons use `DownReason`.
  The crash action formerly called `Kill` is now `GiveUp`.

Run `hew fmt --migrate --root .` for mechanical syntax updates, then review the
result and handle lifecycle and result semantics explicitly. Rebuild native
libraries against the matching compiler, runtime and standard library.

## Tests as ordinary development tools

`hew test` discovers annotated tests throughout a package, compiles each source
file once and runs each selected test in its own process. Exact `path::name`
selectors distinguish identically named tests. Tests use deterministic execution
by default; `#[real_time]` explicitly selects host scheduling when needed.
Failures include a seed that can be used to reproduce deterministic execution.

Use `assert(condition[, message])` for assertions. Comparison failures carry the
source site and rendered operands through native and sandbox execution. Expected
panics are decided from structured Hew fault reports: a process crash, timeout
or explicit nonzero exit does not satisfy `#[should_panic]`.

Results stream as text, JSON events or JUnit. The editor test explorer consumes
those same events, publishes failures at their source locations and offers
seeded reruns. `--watch` supports repeated test runs during editing; captured
stdout and stderr retain their write order. `--trace DIR` saves failure traces
for inspection; a child that exits before producing a trace is reported with
an explicitly incomplete trace.

Documentation fences run through `hew test --doc`. A trailing `// Output:` block
checks the example's output. `hew,no_run` fences compile without execution, and
`hew,ignore` marks an intentionally excluded example. Documentation examples use
the same runner as source tests.

## Compiler and runtime fixes

Imported declarations retain their source identity through checking and lowering,
including generated machine events and private helpers. Record construction
preserves its concrete type when the result is coerced to a trait object.
User-defined ordering is selected through the declared trait identity, so a user
trait with a familiar name cannot acquire compiler capabilities accidentally.

Owned pipeline values drain correctly when actors repeatedly suspend and wake on
multiple workers. Resource cleanup remains checked on normal returns, explicit
close and fault recovery. Windows hardware faults terminate through the runtime's
fault boundary.

## Candidate scope

This is a release candidate, with further v0.6 work still planned. Browser
execution uses the shared frontend and ownership pipeline but has a defined
capability subset. Native-only host operations and unsupported browser features
are reported explicitly; refusal does not count as successful execution.

See [browser runtime behaviour and limits](https://github.com/hew-lang/hew/blob/v0.6.0-rc4/docs/sandbox-vm-divergences.md) for the
current browser capabilities, and the [language guide](https://github.com/hew-lang/hew/blob/v0.6.0-rc4/docs/hew-language-guide.md)
for source migration and everyday APIs.
