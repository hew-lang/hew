# Hew 0.11.2

Hew adds module-private fields on named records, expands `std.cache` and `std.random`, retires superseded top-level compiler aliases, and speeds up both native release compilation and runtime execution.

## Language and tooling

- Named records support module-private fields. Private field access is enforced at the declaring module, including in projected record constructors, and respected in editor completions, hover documentation and syntax highlighting.

- Use `hew build` to produce an executable. Scripts that relied on `hew compile` for intermediate artefacts or IR dumps can switch to `hew tool compile` with the same arguments. Bare `hew file.hew` keeps its existing artefact paths, and playground verification is available as `hew tool playground-verify`.

- The formatter preserves source grouping, macro input and comments more faithfully.

- Editor and LSP tooling colour contextual failure syntax, end import folding spans at their semicolon, normalize empty Markdown heading ranges, and reuse document line offsets and test source snapshots to reduce repeated work.

## Standard library and codecs

- `std.cache` adds cache touch, least-recently-used (LRU) eviction and in-place limit changes, while avoiding repeated scans of live cache entries and buffered streams.

- `std.random` runs weighted draws in Hew across both native and browser targets.

- Standard library fixes move owned arena and vector elements without cloning, preserve numeric errors at representation limits, and preserve UTF-8 byte and scalar boundaries in HTTP and streams.

- YAML decoding preserves indentation in multiline strings.

- Live tooling includes a portable vibration monitor built with generated services.

## Performance and runtime reliability

- Large static `-O2` builds on Linux x86-64 can generate native objects in parallel when sufficient CPU and memory headroom and ELF link tools are available. Hew verifies linked source ranges before using the split object.

- Native code generation places repeated owned child frames in their parent, omits unused coroutine root storage and empty actor request visitors, reduces coroutine cleanup code, and skips heap acquisition for values without backing.

- Ownership verification and type checking share CFG, cleanup, ancestry and dependency state across walks and reuse ownership proofs for wide aggregates.

- Runtime improvements refund a single backing without a temporary map, acquire shared copy backing once, skip empty static callable release walks, retain gossip intent until send, keep the first reply waiter inline, and skip cycle scans for actor waits with an escape.

- Blocking actor sends stay queued when another worker cannot start, and supervised crash counts are verified consistently across native and WASI execution.

## Documentation and builds

- Core examples and language documentation have been refreshed with focused, runnable programs and updated module import guidance.

- Native runtime builds use distinct Cargo outputs to avoid Windows artefact collisions, and CLI documentation describes Windows foreground console interrupt behaviour and forced termination of macOS runs.
