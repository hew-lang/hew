# hew-corpus-expected-failures.txt — Known failures for the hew-corpus-check gate.
#
# Each entry is a repo-root-relative path to a tracked .hew file that currently
# fails `hew check`, optionally followed by a stable diagnostic code when the
# failure class itself is part of the ratchet:
#
#   <path> [E_DIAGNOSTIC_CODE]  # classification and issue
#
# A path carries a code only when the check emits exactly one stable `E_*` and
# the refusal itself carries it. A refusal that emits none, emits two, or whose
# only code comes from a later diagnostic stays unpinned rather than asserting a
# set the compiler does not produce.
#
# The gate exits 1 on any UNEXPECTED failure (not in this list), changed
# diagnostic for an entry that records one, or inventory/outcome drift. A
# listed entry that now compiles is reported in PR gates and fails scheduled
# strict accounting until removed. Pin codes, not diagnostic prose.
#
# Classification categories:
#   deferred-nyi    — Feature not yet implemented in the compiler. The fixture
#                     is correctly written Hew; the compiler has not landed
#                     the feature yet.
#   final-path-limitation — The checker admits the program and the final path
#                     refuses it through the limitation channel (exit 3,
#                     `compiler limitation:`).
#   internal-channel — The checker admits the program and a later stage refuses
#                     it through the internal channel (exit 4, `internal
#                     compiler error:`). Always a compiler defect, never the
#                     program's: every row here names its issue.
#   stale-syntax    — File uses syntax that was removed. Needs migrating
#                     forward rather than bending the compiler back.
#   sandbox-intentional-error — Sandbox fixture explicitly demonstrates a
#                     compile error to the sandbox VM; intentionally invalid.
#   corpus-intentional-refusal — Negative fixture whose whole purpose is to be
#                     refused, and whose owning gate asserts the refusal and its
#                     exit code. Removing the refusal must fail that gate, not
#                     this one.
#   fmt-corpus-incomplete — Formatter roundtrip corpus file that tests AST
#                     round-trip but names undefined traits and helpers because
#                     it is not intended to compile standalone.
#   requires-package-resolver — File imports a `hew::` package that must be
#                     resolved by `hew install` first; `hew check` alone cannot
#                     resolve the dependency. Covered by test-pkg-import.
#   requires-file-import-program — File is one member of a multi-file program
#                     and resolves only when the program's root is compiled.
#                     Covered by its own core-acceptance case.
#   repro-wip       — Reproduction case tracking a specific open bug.
#   downstream-wip  — Downstream / tools fixture not yet updated to current
#                     associated-type requirements.
#
# To add an entry: run the failure through `hew check` to confirm the class,
# add the path + category comment here, and re-run `make hew-check-all`.
# To remove an entry: delete the line once the file compiles clean.
#
# Gate: make hew-check-all (scripts/corpus-ratchet.sh hew-corpus)
