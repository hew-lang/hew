# Hew 0.10.0-rc1

This candidate brings actor-owned memory budgets, native execution foundations
and experimental live authoring together for real-program testing. It continues
edition 2026. Please exercise existing applications as well as the live tools
before the final 0.10.0 release.

## Actor memory budgets follow owned values

`#[max_heap(...)]` now limits managed values retained by an actor: state,
collections, message payloads and supported suspended work. Shared immutable
backing is charged once to each actor retaining it. Exceeding a budget produces
the existing supervised `HeapExceeded` failure.

Admission reserves capacity before publishing a value. Rejected transfers retain
the sender's ownership; accepted transfers move their accounts together with the
reachable values. Cancellation and asynchronous cleanup keep charges until the
values are actually released. Native and browser execution use the same contract.

The limit describes language-managed payload storage. Primitive stack locals,
allocator bookkeeping and operating-system resources have separate lifetimes.
Applications requiring hard process-memory isolation should use their host's
process or component boundary.

Earlier builds applied this annotation only to a scratch arena. Applications
using it should choose a budget for their actual retained values and test their
supervision behaviour. Rebuild native bindings and modules with the matching
compiler, headers and runtime.

## Experimental persistent authoring

The Linux x86_64 SDK includes the compiler, shared runtime, live companions and
prepared transport as one matched installation. With that archive extracted:

```sh
export HEW_SDK=/path/to/extracted/sdk
export PATH="$HEW_SDK/bin:$PATH"
hew --version
hew tool live --runtime "$HEW_SDK/lib/hew/libhew.so"
```

Enter ordinary declarations, statements and expressions. Bindings persist;
initializers execute once. `:type expression` checks without execution,
`:session` lists retained bindings, and `:clear` completes cleanup. Imports resolve
relative to `--project`, which defaults to the current directory. `--show-wrapper`
shows the generated submission source.

Each submission uses compiler-owned type and ownership facts. A fault preserves
completed mutations and the actual remaining fields. Replacing a declaration
leaves existing values attached to the declaration and code that created them.
An interrupted control connection reports an uncertain outcome instead of
replaying the submission.

Native modules are trusted code built against one compatible shared runtime.
Portable components provide isolated instances and typed asynchronous services.
The reference router exercises quiescence, snapshots, conditional replacement,
destination grants and disposal across authenticated nodes. WIT supplies its
C, Hew, Rust and TypeScript boundaries. See the installed
`share/hew/live/README.md` and the [live execution guide](../../hew-live/README.md).

The VS Code companion supports explicit preparation and activation with source
diagnostics and navigation. Observe exposes live status and explicit isolated
preview. Select a matching candidate SDK when using these features.

Linux live execution is qualified. Other platform archives retain their ordinary
compiler tools. Interactive source compilation still has substantial latency;
prepared activation and invocation are separate, faster paths. The candidate is
useful for testing these workflows while that feedback cost is improved.

## Process lines with ordinary Hew

```sh
printf 'first\n\nlast\n' | hew eval --lines 'if line != "" { println(line); }'
hew eval --lines -f filter.hew < events.log
```

The body compiles once and receives an immutable `line: string`. Blank lines and
a final unterminated line follow `std.io.read_line`; loop control and cleanup use
ordinary Hew semantics. Source diagnostics point to the supplied body or file.

## Small libraries use Hew's value model

`std.cache` provides keyed memoization with optional capacity, TTL and bounded
FIFO eviction. Failed loads are returned without caching. Copies retain
independent value semantics and cleanup is automatic:

```hew
import std.cache;

fn main() {
    var values: cache.Cache<string, i64> = cache.new(
        capacity: .Some(2), ttl: .Some(5s)
    ).expect("valid cache limits");
    values.insert("answer", 42);
    println(values.get("answer").expect("cached value"));
}
```

Independent `std.random.Rng` values now execute the same Hew xoshiro256++
implementation on native and browser targets. The module-level random functions
retain their existing generator contract.

Short conditional value expressions format compactly with the existing syntax:
`let sign = if x < 0 { -1 } else { 1 };`.

## Compiler and runtime foundations

The compiler retains semantic ownership facts through SIR and MIR; LLVM consumes
the resulting layouts, cleanup and execution recipes. This candidate fixes
retained generator-account binding and operation-cell publication after coroutine
allocation. Typed stream transfer, cancellation and release keep their checked
contracts while communication and observation paths do less allocation and
unnecessary notification work.

Human diagnostic presentation is now an AOT-compiled Hew component over the
compiler's structured diagnostics. JSON and editor diagnostics retain their
structured interfaces. Tests check observable results, fault identities and
cleanup rather than pinning incidental message wording.
