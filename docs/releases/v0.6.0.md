# Hew v0.6.0

Hew 0.6 brings ownership-aware native compilation, structured concurrency and
typed failures together. It expands value semantics, native I/O and source-level
testing while keeping ordinary calls readable: calls wait, `fork` starts work,
and `await` joins a task.

Existing programs need source migration. Rebuild native libraries against the
matching toolchain; the compiler, runtime and standard library form one SDK.

## Values and compilation

Native compilation passes through HIR, ownership SIR and physical MIR before
LLVM emission. Ownership transfers, loans and cleanup are explicit before
code generation. Suspending calls use frame states and resume switches, with
storage reused between sequential child calls.

Records, enums, arrays, collections, closures, resources and trait objects
compose through the same ownership rules. Nested collection updates preserve
value semantics. Generic associated results, aggregate ordering and mutable
trait-object receivers retain their checked types and state through lowering.
Double-ended iterators support reverse traversal without collecting first.
Zero-sized actor arguments, replies and state use their checked layouts without
emitting memory accesses for empty values.

## Tasks, actors and I/O

```hew
fn square(value: i64) -> i64 {
    sleep(2ms);
    value * value
}

fn main() {
    let pending = fork square(3);
    println(await pending);

    let results = await fork [square(4), square(5)];
    for result in results { println(result); }

    let first = race [square(6), square(7)];
    println("other work");
    println(await first);
}
```

`race [...]` produces a task and accepts calls or existing task handles. It
cancels and drains losing work before publishing the winning result. `select`
waits for readiness; unselected task handles continue running. Batch fork also
accepts tuples for results of different types.

Task lifetimes follow values through patterns, aggregates, callbacks and
generic calls. Actor calls, generators and I/O participate in structured
cleanup. Supervision keeps child roles stable across restarts, and actor
teardown retains its owner while cleanup hooks run.

Idle scheduling waits for events and actual deadlines. Socket, pipe and TLS
operations suspend without occupying a scheduler worker. Process capture
drains stdout and stderr concurrently and owns cancellation, termination and
reaping. Nonblocking sink writes retain accepted partial items; `Full` means
no bytes were accepted.

On macOS, process creation keeps each child's pipes isolated so an unrelated
child cannot retain a writer and delay EOF.

Distributed sends use manager-issued claims tied to the authenticated peer
and route. Authentication and JWT validation reject invalid trust inputs.

## Source and failures

- Records use `type`, enum variants use dotted forms, and matches are exhaustive.
- Keyed construction uses braces, including `spawn Worker { id: 1 }`.
- Typed locals may defer initialization when every path assigns before use.
- `?` propagates typed failures from functions declaring `fails E`.
- `defer err` runs on failure propagation, faults and cancellation, in the same
  cleanup order as ordinary defers. Returning a plain `Result.Err` or
  `Option.None` value does not trigger it.
- Optional chaining preserves ownership and borrowing through resource access.
- Package membership and package-root imports are anchored to the nearest
  `hew.toml`; ambiguous sibling and root imports are diagnosed.

Strings preserve UTF-8 and embedded NUL contents. Byte decoding is explicitly
fallible or lossy. JSON, CBOR, YAML, TOML and MessagePack share typed codec
shapes across native execution and the sandbox VM, including exact integer
ranges and typed decode errors.

## Testing and tools

Source tests support exact selectors, structured failures and seeded reruns.
Property tests generate typed values and shrink failing examples; benchmark
suites support calibrated measurements and saved-result comparisons. Native
and sandbox coverage use the same source identities.

The LSP uses checked binding and associated-type identities for renames and
actor replies. Editor grammars follow the current task and construction syntax.
Debug metadata tracks local initialization and lifetime across suspension;
unavailable values do not expose stale frame contents.

The registry client supports official slash wire identities and custom
registry identity modes while retaining signature checks.

## Migration and platforms

Use `hew fmt --migrate --root .`, review its output, then check the project.
Resolve package dependencies before checker-backed migration. Migration checks
one semantic unit at a time to limit memory use with overlapping import graphs.
See the [migration guide](../migrations/v0.6.0.md) for the changed APIs and syntax.

The SDK ships for Linux x86_64 and ARM64, macOS Intel and Apple silicon,
Windows x86_64, and FreeBSD x86_64. Prebuilt FreeBSD tools require FreeBSD 15.1
or newer; FreeBSD ARM64 receives build and link checks without an SDK archive.

Native execution and supported sandbox operations share language semantics.
Native-only capabilities retain their documented restrictions; consult the
[capability matrix](../wasm-capability-matrix.md) when targeting the sandbox.
